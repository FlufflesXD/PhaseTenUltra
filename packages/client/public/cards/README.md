# ?? Card Art Asset Directory

Drop your card image files directly into this directory (packages/client/public/cards/).
Images should be in **PNG** (or **WebP / SVG / JPG**) format.
Recommended aspect ratio: standard playing card ratio (~**2.5 : 3.5** or **5:7**, e.g. **500x700px** or **250x350px**).
